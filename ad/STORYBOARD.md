# 分镜与衔接

基准：20 × 4 秒 = 80 秒；每镜表达一个信息点。画面使用真实产品内容与必要功能标签，不额外插入章节标题。运动集中在进入、解释与接出，读字时保留短暂停留。

| 秒 | 分镜 | 内容与动作 | 声音重点 |
| --- | --- | --- | --- |
| 0–4 | 01-point | 巨大定位点退开，路线描出定位符，地图展开 | 退镜气流、纸面划线、点落位 |
| 4–8 | 02-campus | 简化路网转为原始导览图，旋转推近 | 纸面展开、短推镜 |
| 8–12 | 03-pocket | 地图退入银色手机，机身左右转动 | 柔和滑动、机身落位 |
| 12–16 | 04-search | 搜索图书馆，结果依次出现并选中 | 输入轻敲、选择、放大 |
| 16–20 | 05-route | 绘出宿舍到图书馆的实际步行路线 | 路线摩擦、地点钉轻击 |
| 20–24 | 06-options | 五种路线分解为不同几何轨迹 | 错位滑入与短促落位 |
| 24–28 | 07-weather | 太阳旋转、天气值显现，太阳移向建筑 | 空气转动、温度落位 |
| 28–32 | 08-shadow | 建筑落下，投影展开，路径沿阴影绕行 | 建筑轻扣、投影气流、画线 |
| 32–36 | 09-rain | 雨滴落在连廊外，路径穿过有顶空间 | 低音量雨滴、屋顶拼合 |
| 36–40 | 10-access | 台阶旁展开坡道，沿坡道行进 | 路径描绘、平滑行进 |
| 40–44 | 11-live | 位置移动，同一目的地接入新路线 | 地图平移、路线更新确认 |
| 44–48 | 12-places | 图书馆、食堂、体育场、服务中心连续展开 | 地点错位滑入、定位钉 |
| 48–52 | 13-import | 教务表单的数据转为课程块 | 导入点击、课程逐块落位 |
| 52–56 | 14-week | 课程展开为一周，再推向周一 | 周列快速轻敲、推镜 |
| 56–60 | 15-day | 从早到晚纵向展开全部 13 小节 | 选择、两次短滚动 |
| 60–64 | 16-classroute | 点击课程地点，把课程接到地图 | 点击、横向气流、地点落位 |
| 64–68 | 17-plan | 路径连接上课、用餐、下午课程和运动 | 路径摩擦、日程节点 |
| 68–72 | 18-together | 地图、课表、日程三台手机展开后收拢 | 阵列展开、集中收拢 |
| 72–76 | 19-signature | 路径逐笔写出 NJUST，画下划线和定位符 | 与每笔共享时间的纸面摩擦 |
| 76–80 | 20-end | 校徽、NJustMap、江阴校区落版，定位点收尾 | 克制落位、下划线、最后轻点 |

片中课程与日程为统一演示情境。运镜、几何路径与笔画均由 Fourier 宿主绝对时间求值；没有浏览器墙钟动画或隐藏的全局逐帧状态。
