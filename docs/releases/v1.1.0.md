# NJustMap v1.1.0

行程路线预览与餐后返寝更新。

- 修复日程导航起点被当前位置覆盖的问题：计划中的「致新楼 → 体育场」等路线保留指定起终点，普通实时导航仍随定位更新。
- 每段行程新增与「导航」并列的「路线预览」。
- 每日行程底部新增「全天路程预览」，按顺序播放课程、用餐和返寝路线，支持暂停、重播及前后段切换。
- 修复预览圆点移动时的抖动，使圆点与地图相机同步逐帧更新。
- 早餐、午餐、晚餐后均先返回寝室，再前往下一安排；自动预留返寝及后续步行时间，必要时提前安排用餐。
- 未设置地点或路线不可达时明确提示，不生成虚假的步行路线。
- 「我的」新增作者 v0idfun 的 B 站、抖音主页入口，「应用更新」移至页面最底部。

[在线使用](https://lizi-eosin.vercel.app/app) · [官网](https://lizi-eosin.vercel.app)

## 下载

- **njustmap-android.apk**：Android 安装包；签名方式见 BUILD-INFO.txt。同一正式签名的 v1.0.0 可覆盖升级。
- **.aab**：Android 应用商店上传包。
- **njustmap-ios-simulator.zip**：仅供 iOS 模拟器使用，不能直接安装到 iPhone。
- **njustmap-web.tar.gz**：包含静态页面与 Node API 的 Web 部署包。
- **BUILD-INFO.txt / SHA256SUMS.txt**：构建信息与附件校验值。
