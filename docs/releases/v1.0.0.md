# NJustMap v1.0.0

南京理工大学江阴校区校园导航 v1。

- 新增自动更新检测：启动与回到前台时检查 GitHub 正式版，成功检查间隔 6 小时。
- 「我的 → 应用更新」可随时手动检查；发现新版本展示版本说明，Android 可下载更新安装包。
- 自动检查失败不弹窗打断使用，可在「我的」查看状态并重试；支持跳过本次提醒。
- 保留校园地图、步行与遮阴路线、实时定位、课表导入和每日行程。
- Android 从 v1 起使用固定发布签名，后续正式版可覆盖升级。

[在线使用](https://lizi-eosin.vercel.app/app) · [官网](https://lizi-eosin.vercel.app)

## 下载

- **njustmap-android.apk**：正式签名的 Android 安装包。下载后打开并按系统提示安装。
- **.aab**：Android 应用商店上传包。
- **njustmap-ios-simulator.zip**：iOS 模拟器 App，不能直接安装到 iPhone；尚未发布 App Store / TestFlight 版本。
- **njustmap-web.tar.gz**：Web 部署包，包含静态网页与 Node API。
- **BUILD-INFO.txt / SHA256SUMS.txt**：构建信息与校验值。

旧 0.x 测试版使用 debug 签名，可能无法直接覆盖安装 v1。请先在「我的」导出课表备份，并记录寝室等设置，再卸载旧版安装 v1。v1 之后请保留同一发布签名。

更新检测负责提示与跳转下载，安装须由用户在系统中确认。旧版没有更新检测功能，需要先手动安装本版。
